# Trabjo Practico GIT - Metodologia de Sistemas I

## Introduccion

Este Trabajo Practico busca explicar los comandos de Git vistos durante las clases de Metodologia de Sistemas I, asi como tambien practicar el uso del mismo en un entorno practico simulado.

## Explicacion de Ramas

Decidimos seguir una nomenclatura especifica a la hora de crear ramas, especificando el tipo y las iniciales del integrante trabajando en la misma.
Siempre se utiliza como prefijo la caracteristica a realizar y al final las iniciales.

Por ejemplo:

**feature/xx-JR** -> Para agregar nuevas funcionalidades

**fix/xx-ML** -> Para corregir errores

**docs/xx-CZ** -> Para agregar documentacion tecnica
